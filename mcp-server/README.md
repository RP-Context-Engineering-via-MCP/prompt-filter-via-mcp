# MCP Server

This is the backend server for the Claude-like Chat App, implementing the Model Context Protocol (MCP).

## Prerequisites

- Node.js (v18 or higher recommended)
- `npm` installed

## Installation

```bash
npm install
```

## Running the Server

To start the server:

```bash
npm start
```

This command runs `node src/index.js`.
The server will start on port **3001**.
